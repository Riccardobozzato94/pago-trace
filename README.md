# PagoTrace

Sollecitare una fattura è un lavoro di tono prima che di testo. A tre giorni di ritardo serve una frase gentile; a venti serve un ultimo avviso. La regola non la inventa il modello: sta scritta nel codice.

Questa pagina mostra tre fatture inventate, prepara il promemoria con il tono giusto e ti lascia rileggerlo, firmarlo e segnarlo come inviato. Non invia nulla: "inviato" significa che lo hai spedito tu.

**Apri lo strumento:** https://riccardobozzato94.github.io/pago-trace/

## Perché è pubblico

È un esempio ispezionabile di automazione con supervisione umana: il sistema propone, la persona decide. Nessuna API, nessun segreto, solo HTML e JavaScript leggibili.

## Cosa non fa

- Non scrive ai tuoi clienti e non collega caselle email.
- Non usa dati reali: clienti, importi e giorni sono inventati.
- Non calcola interessi o azioni legali: prepara solo un testo.
