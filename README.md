# PagoTrace

Prepara i promemoria per le fatture in ritardo. Regola: 3 giorni → gentile, 10 → deciso, 20 → ultimo avviso. Rileggi il testo, firma, poi segna come inviato.

**Apri lo strumento:** https://riccardobozzato94.github.io/pago-trace/

Nessun account, nessuna installazione, nessun costo. Tutti i dati sono di esempio e nessun invio è automatico.
